# Held-out 03: посуда

Статус: независимый held-out поток для финальной оценки frozen pipeline. Не используется для настройки алгоритма.

## Назначение

Поток содержит 20 controlled-кадров и 10 локальных visual types посуды и сервировки. Он проверяет похожие круглые типы, изменение количества тарелок и ложек, disappearance/reappearance, положение, цвет, размер и поворот.

## Visual types

| Объект | Класс | `visual_type_id` |
| --- | --- | --- |
| Круглая тарелка | `circle` | `circle_subclass_01` |
| Миска | `circle` | `circle_subclass_02` |
| Блюдце | `circle` | `circle_subclass_03` |
| Овальное блюдо | `oval` | `oval_subclass_01` |
| Квадратная тарелка | `square` | `square_subclass_01` |
| Поднос | `rectangle` | `rectangle_subclass_01` |
| Сложенная салфетка | `rectangle` | `rectangle_subclass_02` |
| Треугольная тарелка | `triangle` | `triangle_subclass_01` |
| Чашка | `undefined` | `undefined_subclass_01` |
| Ложка | `undefined` | `undefined_subclass_02` |

Салфетка компактна, не лежит под другими предметами и размечается отдельным объектом.

## Сценарий

- F01-F05: появляется блюдце, тарелка перемещается, добавляется ложка, миска исчезает;
- F06-F10: появляются овальное блюдо, квадратная тарелка и поднос; чашка меняет цвет, блюдце увеличивается;
- F11-F14: поднос перемещается, появляется салфетка, затем поворачивается и уменьшается, появляется треугольная тарелка;
- F15-F18: чашка исчезает и возвращается, добавляется вторая тарелка, возвращается миска;
- F19-F20: блюдце исчезает и возвращается, количество ложек уменьшается.

## Технические правила

- 20 RGB PNG кадров `640 x 480`, формат `png_rgb`;
- постоянный темно-синий фон с легким градиентом;
- bbox по фактическим RGB-пикселям с запасом `2 px`;
- минимальный bbox gap `20 px`, касания и перекрытия запрещены;
- разметка всех 19 соседних сравнений полная;
- вариации хранятся в `notes` и не расширяют schema.
