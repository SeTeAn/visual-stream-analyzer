# OCID ARID10 fruits example stream

This directory contains one compact RGB sequence selected from the Object Clutter Indoor Dataset (OCID). It can be used as an input example for Visual Stream Analyzer. No OCID label masks, depth maps, point clouds, or evaluation annotations are included.

## Contents

- Sequence: `ARID10/table/top/fruits/seq10`
- Frames: 11 ordered RGB PNG images
- Resolution: 640 × 480 pixels
- Manifest: `stream-input-0.1`
- Pixel modifications: none; files were renamed to stable sequential names
